PrsfMenuForge — גרסת מקור 0.2
==================================

מנהל פריטים בתפריט הלחיצה הימנית של Windows 11.

איך מפעילים?
1. חלץ את תיקיית PrsfMenuForge מתוך ה-ZIP למקום במחשב.
2. לחץ פעמיים על "הפעל.bat". אין צורך בקימפול או בהתקנת Python.
3. עבור ללשונית "שולחן העבודה" כדי לראות, בין השאר, פריטים של Git ו-Visual Studio.
4. בחר שורה ואז "הסתר מהתפריט". לשחזור בחר שוב ואז "הצג מחדש".
5. להוספה: "הוסף תוכנה", בחר שם וקובץ exe ואת המקום בתפריט.
6. כדי למחוק רישום של פריט: בחר שורה ולחץ "מחק" (אדום).
   קרא את חלון האישור. רק רישום התפריט נמחק — לא קובץ התוכנה.
   לפני המחיקה נשמר קובץ .reg, שאפשר לייבא ידנית כדי להחזיר את הרישום.
7. כדי לשנות פריט ברמת כל המשתמשים, לחץ "הפעל כמנהל" ואשר UAC.

בטיחות:
* הוספה לא מתקינה את התוכנה, רק מוסיפה קיצור בתפריט.
* הסתרה לא מסירה את התוכנה או קבציה.
* מחיקה מסירה רק את רישום פריט התפריט, אינה מסירה את התוכנה,
  אינה הפיכה בכפתור "החזר", אבל ניתן לשחזר מגיבוי ה-.reg.
* לפני שינוי ברישום קיים נשמר קובץ .reg לגיבוי.
* הגיבויים נמצאים תחת %LOCALAPPDATA%\PrsfMenuForge\Backups
* כפתור "גיבויים" פותח את התיקייה.
* פקודות מערכת מזוהות מוגנות מפני שינוי ומחיקה מתוך התוכנה.
* שינויים מסוימים ייראו אחרי פתיחה מחדש של סייר Windows או כניסה מחדש.

מגבלות ידועות:
- מציג פקודות shell קלאסיות ותוספי COM הנרשמים במספר מיקומים נפוצים.
- לא יכול לזהות באופן מלא את התפריט החדש של Windows 11, פעולות מובנות,
  פקודות המופיעות רק בתנאים מסוימים, פקודות לפי סוג קובץ ספציפי,
  או תוספי אפליקציות מודרניות המוגדרים דרך חבילות.
- שמות וסמלים מסוימים מגיעים ממשאבי Windows בצורה דינמית; במקרים אלו
  התוכנה תציג שם מזהה פנימי או תישאר ללא סמל, ולא תמציא שם שגוי.
- חסימה של תוסף COM עשויה להסתיר אותו גם מתפריטים אחרים.
- שינויים של כל המשתמשים עשויים לדרוש אישור מנהל מערכת.
- ייתכן שמדיניות אבטחה ארגונית תמנע חלק מהשינויים.

גרסה זו לא נבדקה בהרצה על Windows במחשב הנוכחי (סביבת הפיתוח אינה Windows).
לכן חשוב לבדוק תחילה פריט לא חיוני ולשמור את הגיבוי לפני ביצוע שינויים רבים.

מקור: מסמכי Microsoft על shell verbs והרחבות תפריט (Win32).
