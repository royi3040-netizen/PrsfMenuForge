# PrsfMenuForge

**PrsfMenuForge** — מנהל תפריט הלחיצה הימנית ב-Windows 11.

## גרסה: 0.2

ממשק בעברית (PowerShell 5.1 + WPF), המאפשר להציג ולנהל חלק מהפקודות בתפריט הלחיצה הימנית (Context Menu):

- רשימת פריטים לפי סוג: שולחן עבודה, תיקיות, קבצים וכוננים
- חיפוש ופרטים כולל סמל כאשר אפשר לחלץ אותו
- הסתרה והצגה מחדש של פקודות מזוהות
- הוספת פקודות להפעלת תוכנות
- מחיקת פריט שנבחר מהתפריט (ללא הסרת התוכנה), עם אישור וגיבוי ‎`.reg` לשחזור ידני
- פסי גלילה כהים ברשימת הפריטים, בהתאם לעיצוב הממשק
- גיבוי של מפתחות Registry לפני שינוי במפתח קיים

## הפעלה

1. הורידו את קוד המקור וחלצו את הקבצים לתיקייה.
2. ב-Windows 11 הפעילו את `הפעל.bat`.
3. עיינו ברשימה ובצעו שינויים בזהירות. מומלץ לבדוק תחילה על פריט לא חיוני.

אין צורך בהתקנת Python ואין קובץ EXE בגרסה זו.

## מגבלות ובטיחות

- הכלי מזהה פקודות Shell קלאסיות וחלק מהרחבות COM; הוא **אינו** מבטיח כיסוי מלא של תפריטי Windows 11 החדשים.
- שינויי Registry עלולים לדרוש הרשאות מנהל, וההתנהגות תלויה בהרשאות ובתוספים מותקנים.
- מחיקה מסירה את **רישום פריט התפריט** (בניגוד להסתרה הפיכה); לשחזור ייתכן שתצטרכו לייבא ידנית את קובץ ה־`.reg` מתוך תיקיית הגיבויים.
- לפני עריכה, ודאו שקיימת נקודת שחזור וגיבויים זמינים; אל תשביתו רכיבי Windows חיוניים.
- **לא בוצעה בדיקת הפעלה ב-Windows 11 בסביבה זו.** מדובר בגרסת מקור ראשונית לצורך בדיקה.
- הגיבויים המקומיים נשמרים תחת `%LOCALAPPDATA%\PrsfMenuForge\Backups`.

ראו גם `README-עברית.txt` להוראות מפורטות.
